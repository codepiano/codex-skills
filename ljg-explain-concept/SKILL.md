# 概念解剖师（Codex 版）

把一个概念从“定义记忆”升级到“结构理解 + 可迁移洞见”。

## 上游仓库

- Source: `https://github.com/lijigang/ljg-explain-concept`
- 更新同步示例：`git clone --depth=1 https://github.com/lijigang/ljg-explain-concept.git`

## 输入支持

- 概念词（如“熵”“反脆弱”“自由意志”）
- 可选上下文（用户领域、应用场景、阅读背景）

## 执行流程

### 1) 预处理

- 澄清通行定义与常见误解。
- 提取概念核心词素与边界（它不是什么）。

### 2) 八维探索

每个维度输出 2-3 条高密度洞见：
1. 历史溯源
2. 辩证分析（反题 -> 综合）
3. 现象学还原（回到体验）
4. 语言学解构（词源/语义场）
5. 数学或形式化表达
6. 存在论审视
7. 美学维度
8. 元哲学反思（隐喻与遮蔽）

### 3) 内观与提炼

- 第一人称视角：若“我就是这个概念”，我如何看世界。
- 提取八维共同指向的深层结构。

### 4) 顿悟压缩

必须给出：
- `The One` 公式（`概念 = ...`）
- 费曼式一句话
- 概念 ASCII 拓扑图（只用基础 ASCII 字符）

### 5) 输出与落地（用户要求保存时）

- 默认输出 Markdown；用户要求可输出 Org-mode。
- 保存路径：`~/Documents/notes/`
- 文件名：`{timestamp}--概念解剖-{concept}__concept.md`（或 `__concept.org`）

## 质量标准

- 不做百科式堆砌，强调结构与洞见。
- 每个维度必须有具体信息增量。
- 公式与一句话要能解释并指导思考。
- ASCII 图禁止 Unicode 线框字符。
